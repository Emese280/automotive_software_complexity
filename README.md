# automotive_software_complexity
Developer oriented research on software complexity in automotive embedded systems.

Nagy mennyiségű, több millió sornyi kód okai az autóiparban és ennek okai, karbantartása.

Témakörök:
- C nyelv használata autóiparban
- ECU architektúra
- AUTOSAR
- Generált kód
- legacy szoftverek
- Technikai adósság
- Spagetti kód
- Repó mérete
- Miért nehéz újraírni a legacy rendszereket
